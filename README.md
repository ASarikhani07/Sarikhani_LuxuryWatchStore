Luxury Watch Store

A simple watch store project using Django REST Framework.

This project includes products, brands, categories, product images, colors and customer wishlists.

Built with Python, Django, DRF and SQLite.

To run the project:

    pip install -r requirements.txt
    python manage.py migrate
    python manage.py runserver

API URLs:

    /api/products/
    /api/products/<slug>/
    /api/luxury-special/
    /api/me/wishlist/
